## Student Marks Management System

##  Introduction
The Student Marks Management System is a C programming project designed to store, manage and display students' marks in different subjects.

## Objectives
- To store student marks.
- To calculate total marks.
- To calculate average marks.
- To display student results.
- To understand the use of C programming concepts.

## Technologies Used
- Programming Language: C
- Software: Visual Studio Code
- Compiler: GCC

## Concepts Used
- Structures
- Variables
- Input and Output
- Conditional Statements
- Loops

## Project Files
- student_marks.c – Main source code.
- student_marks.exe – Executable program.
- Project_Report.pdf – Project documentation.

## Conclusion
This project helped in understanding the practical implementation of C programming concepts and developing a simple student marks management system.
